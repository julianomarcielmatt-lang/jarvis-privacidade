JARVIS · ATUALIZADA EM 23/10/2026

O que é o JARVIS

O JARVIS é um aplicativo para Windows que roda no computador do usuário. Ele pode se conectar às contas Google que o próprio usuário autorizar, para mostrar na tela as playlists do YouTube e os e-mails novos do Gmail.

Quais dados do Google o JARVIS usa

  • YouTube (permissão de leitura): os nomes e o conteúdo das playlists da conta, para tocar no próprio JARVIS.
  • Gmail: a lista de e-mails não lidos da caixa de entrada (remetente, assunto, trecho e data) e o texto do e-mail que o usuário abrir. Quando o usuário lê um e-mail no JARVIS, o JARVIS tira a marca de "não lido" desse e-mail no Gmail. O JARVIS não apaga, não move e não envia e-mails.

Onde os dados ficam

  • Os dados vão direto do Google para o computador do usuário. O JARVIS não tem servidor e não envia esses dados a terceiros.
  • As autorizações de acesso ficam guardadas no Gerenciador de Credenciais do Windows, no computador do usuário.
  • Os e-mails não são gravados em arquivo. O JARVIS guarda só os endereços das contas conectadas e a lista dos e-mails já abertos, para mostrá-los como lidos.
  • Os dados do Google não são usados para publicidade, não são vendidos e não são usados para treinar modelos de inteligência artificial.

Como desconectar

No JARVIS, na tela E-MAILS, o botão × ao lado de cada conta a desconecta e apaga a autorização do computador. Também é possível revogar o acesso a qualquer momento em myaccount.google.com/permissions.

Uso dos dados do Google

O uso e a transferência das informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, inclusive os requisitos de Uso Limitado.
